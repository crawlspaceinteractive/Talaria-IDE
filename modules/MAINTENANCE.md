# Maintainer’s Guide  
### keeping the manual alive and consistent

**Purpose**  
Explain how to care for the manual itself. Code has maintainers; ethics should too.

**Highlights**
- Semantic versioning `major.minor.revision`  
- Changelog table at file bottom  
- Archive don’t delete  
- Plain language first  
- Peer review for drift  
- Monthly sleep mode

> *“Every edit is a promise to remember.”*
