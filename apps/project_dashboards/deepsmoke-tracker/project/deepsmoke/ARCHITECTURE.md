# Deepsmoke — Architecture

- **index.html** — importmap (three@0.160 jsdelivr), Tailwind, Pixelify Sans, pixel CSS: `.btn-brass/.btn-cobalt/.pixel-panel` are solid #9c9c9c + #000 border + inset-shadow bevel, white text w/ black shadow (image-based GUI frames deleted by user — do not re-add); `.pixel-slider` still uses SLIDER_BAR/GEM_HANDLE images; `.gp-focus` adds controller-focus outline/brightness; `#game-root [class*="rounded"]{border-radius:0!important}`; loads main.js. Menu bg = tiled procedural dirt (main.js `dirtURL` dataURL).
- **textures.js** — `makeTextures()` → procedural 32px CanvasTextures for terrain/hazards plus ore veins (`copperOre/ironOre/silverOre/goldOre`), player-built panel blocks (`placed`), and player-laid `haulerTrack` rails used by the steam hauler route system.
- **world.js** — `BLOCK` (ids 0–36 incl. terrain/hazards + buildables + `TRACK` rail block), `HARDNESS`, `SX=48 SY=352 SZ=48 GROUND_Y=288`, `PACKABLE`; `createWorld(scene, textures)` now generates an 8× taller world with macro/micro height shaping and biome bands for **mountains/deserts/valleys/buttes/plains/floating_islands**, camp flatten blend near spawn, deep cave noise, expanded room depth, floating landmass generation, plains+sky-island castle structure stamps, and rare steam-engine chamber setpieces with segment carts (minecart replacement flavor). Spawn is forced onto a plains column and clamped to a reasonable height band around `GROUND_Y`. Exposes `world.biomeAt(x,z)` for runtime systems (weather/atmosphere). Keeps stair entrance edits, cave flora, ores, chunk streaming, instanced rebuild/dirty flush, and physics/raycast API.
- **items.js** — `createItems(scene, world, audio, textures, icons)` → pickups (`relic/can/ore/block`, magnet+collect via `cb.onPickup(who,type,pos,kind)`; 'block' pickups render item icons), `throwCan` projectiles (grub catch → `cb.onGrubCatch`), `flyOre`, particle pool (`burst`, `steam`), `update(dt,{player,grub},cb)`.
- **inventory.js** — `ITEMS` registry (blocks/tools/smelts + hauler logistics items: `hauler_track`, `cargo_cart`, `steam_hauler`), `BLOCK_DROP`, 36-slot inventory ops, recipes (track/cargo cart/steam hauler crafts at bench), oven smelting, and icon generation (custom cart + steam-hauler icon paths).
- **trees.js** — `createTrees(scene, world, items, audio, textures)` → felling physics: `fell(baseCell, cells, dir)` topples log+leaf cell groups as animated meshes, then spawns block drops; `update(dt)`, `dispose()`.
- **hotbar.js** — `createHotbar(root, iconURL)` → DOM hotbar, 9 bag slots stacked VERTICALLY down the right edge (desktop: vertically centered right:10px; touch: right:74px top:74px below PACK) so it never covers Grub's bottom-center HUD meter. `{setInv, render(force?), show}`; renders on `inv.rev` change; select via tap/1-9/wheel.
- **mobs.js** — `createMobs(scene, world, audio)` → 12 ambient box-built critters (chicken/pig/cow/goat; front -Z, facing atan2+PI), spawn r12–36 around world.spawn, wander AI + hop-when-blocked, leg swing/head bob. `{update(dt), dispose()}`.
- **partner.js** — `createPartner(scene, world, audio, items)` + shared character rig builder: `initGoblinModel(renderer)` loads the Star `goblin_miner` GLB once (Draco/KTX2/meshopt decoders), and `buildGoblin()` instantiates that base model for Grub/Bub/Tub/co-op mates. Rigs expose animation controls (`setAnim`, `updateAnim`) plus live visual tuning hooks (`setTextureRGB`, `setScaleMul`, `setVisual`) that tint cloned GLB materials by per-channel multipliers and scale each rig non-destructively. When GLB clips are missing/unmatched, `updateAnim` runs a procedural idle/walk/work motion pass so camp NPCs still animate through the rigged model. `includeShell:false` disables procedural shell parts for GLB-only NPCs. Grub AI loop remains follow/fetch/rescue with fuel/drill behavior and `revive(fuel)`.
- **camp-models.js** — shared camp-prop model pipeline for `ore_vacuum_station` + `blacksmiths_forge`: one-time GLTF preload (`initCampPropModels(renderer)`), mesh normalization/ground anchoring, +PI yaw correction to match world facing, live per-model transform overrides (`scale`, `x/y/z`, `yaw`) with exported get/set/reset APIs, pending+live mount tracking for runtime re-tuning, and safe fallback retention on load failure. Current default overrides match creator tune values (`vacuum scale 1.35 yaw 135deg`, `forge scale 1.4 x 2 z 0 yaw 5deg`).
- **gamepad.js** — portable `GamepadManager` wrapper + `BTN/AXIS` constants; rAF polling, edge detection (`justPressed/Released`), per-pad remapping, optional chords, stick deadzone helpers, and optional rumble.
- **input.js** — `createInput(root, canvas)` now merges keyboard/mouse/touch with gamepad: LS move, RS look, RT drill, A jump, B use, X throw, Y transfer, LB/RB place, SELECT/L3 inventory, d-pad L/R hotbar wheel; still supports pointer-lock/drag look + touch joystick/buttons + contextual TALK. Exposes `gamepad` + `gamepadIndex` for menu/navigation handling in main.
- **upgrades.js** — persistent profile (`loadProfile/saveProfile`) + forge tracks (`drill/tank/plate`) and ore metadata maps (`ORE_KEYS`, `ORE_INFO`, `ORE_BLOCK_KEY`) used for mining tiers, fuel cap, hazard plating, and banking. Profile now carries sanitized `playerName` (default `MINER`) for menu/lobby identity.
- **npcs.js** — HQ camp builder still provides Bub/Tub, fire/tents, forge props, ore vacuum, and project structures; requests camp model preload at runtime, registers forge/vacuum model attach points with procedural fallback meshes, and owns the **steam hauler dock** (locomotive + dynamic segment carts) with API hooks: `haulerDockPos`, `haulerChestCell`, `setHaulerState(active,carts,built)` and `setRigVisual(id,{r,g,b,scale})`. Hauler visual now stays hidden until commissioned (`built=true`). Bub/Tub use GLB-only rigs (`includeShell:false`) with animation intents, and Tub’s facing is fixed to the forge.
- **ui.js** — shared drag-cursor panel system now includes `openHauler(ctx)` in addition to inventory/chest/oven/camp/shop. Hauler panel supports commissioning from crafted `steam_hauler`, cart cargo grid + bag transfer, cart expansion, live connected-track readout, and dispatch gating on track length. Layer id remains `#ui-layer` for controller focus.
- **ore-model.js** — shared recolorable `ore_crystal.glb` pipeline: `initOreCrystalModel(renderer)` one-time load (Star decoders), normalized to max-dim 0.46 + origin-centered; `buildOreCrystal(colorHex,{emissiveIntensity,scale})` → wrapper Group or null until loaded (callers keep procedural fallback). Clones share template geometry; tinted materials cached per `${hex}:${emissive}:${srcMat.uuid}` — no per-pickup disposal.
- **player-models.js** — player GLB loader/cache for `goblin_mining_mech` + `mech_drill_bit` (Draco/KTX2/meshopt), with normalization/fallback-safe attach and live pose override APIs (`getPlayerModelPoses`, `setPlayerModelPoseOverride`, `getPlayerModelPoseRef`). Exposes first-person layer/render-priority helper so owner viewmodels are tagged consistently (fallback + GLB). Runtime applies per-part transforms for `mech`, `pilot`, `drill` (FP), and `drillTP` (third-person rigs' drill; current tuned defaults: `scale 0.85 x 0.4 y -0.13 z 0.51`) (x/y/z, scale, pitch/yaw/roll) to mounted states so `tunable()` sliders update immediately in-game; `applyPlayerPoseState` picks `drillTP` when `state.thirdPerson`. Per-state `hideCockpitPilot` keeps the local owner rig cockpit-pilot hidden. Per-state `thirdPerson: true` skips FP layer tagging and instead applies `applyMechTint` (cloned materials lerped 0.4 toward `state.mechTint`, tracked in `state.tintedMats`, disposed with the rig). Exports `PLAYER_EYE_HEIGHT=1.55` (must match player.js camera offset) and `createMateMechRig({tint})` → full third-person crewmate mech: grp → eye@1.55 → mechMount (mech GLB + visible `buildGoblin({includeShell:false})` pilot) + rightArm@(0.42,-0.42,-0.7) → drillMount (drill GLB) — same hierarchy as FP so pose sliders drive both views; returns `{grp,setAnim,updateAnim,dispose}`.
- **player.js** — `createPlayer(scene, world, camera, audio, input, items, profile, renderer)` → FP movement/look + gameplay loop, with first-person rig now model-backed: mech suit mounts on camera rig, drill-bit GLB mounts to the right-arm hardpoint, and a nested goblin cockpit pilot remains hidden on the local owner rig so cockpit view stays purely mech interior; procedural gauntlet/drill meshes remain as fallback if model decode fails. Hard-landing logic now tracks airborne peak height and, on drops `>10` blocks, applies a brief movement-lock window plus local cockpit shake and fires `cb.onHardLanding({drop,pos})`.
- **hud.js** — `createHUD(root)` → pixel steampunk HUD canvas (helmet image overlay removed): pixel unit `P=max(2,round(min(W,H)/220))`, dials painted per-pixel on a 34×34 offscreen canvas then blitted chunky (smoothing off; FUEL scale P, GRUB scale ~0.6P), riveted brass `plate()` + dark-glass `face()` helpers, ore/can/block readout glass, top-center SCORE/DEPTH plate, pixel crosshair + 12-segment drill ring, prompt & comms feed (GRUB/BUB/TUB colors), low-fuel vignette, `flash()`, LOCKED banner with hazard-stripe pattern edges. API unchanged: `say/update(dt,d)/flash/reset`.
- **coop.js** — ALL multiplayer (Star Multiplayer SDK): exports `mp`, shared `MSG` enum (BEGIN, BLOCK_BREAK/PLACE/FILL_REQUEST, CHEST_OPEN/MOVE_REQUEST, CHEST_CLOSE), and `createCoopClient(scene)`. Host-authoritative edits (1.1): handlers validate digId + sender distance (REACH 12, CARVE_REACH 40 batch, CARVE_MAX 220) + PLACEABLE whitelist + first-placement-wins occupancy; silent rejects (console.debug). `shared.edits` = k→(-1 air | blockId placed/filled; FILL = cave-in rubble, ROCK only). Chest sync (1.2): `shared.chests[k]={size:18|36,lockedBy,slots:{i:{id,n}|0}}` (sparse, 0=empty, tombstone size:0 on break, never delete keys); OPEN grants a lock (busy reject if holder still digging, else stale-steal), MOVE = validated slot deltas ≤12/req (ITEMS id + stack cap), CLOSE releases. Client: `reportBreak/reportCarve/reportPlace/reportFill` predict-then-request; `bindChests(getContainer,onRemoteChange)` + `chestOpen(k,container,onLockLost)`('solo'|'busy'|'ok'; adopts confirmed contents or first-opener seeds via diff)/`chestChanged`/`chestClosed` (snapshot-diff → chunked moves); `tick` reconciles edits, syncs pos, lerps mates, converges remote chests + fires onLockLost. Co-op identity now syncs `mp.me.playerName` (set via `setPlayerName()`), and mates render overhead sprite nametags that refresh if a player renames. Mates still render as FULL third-person mechs via `createMateMechRig({tint: MATE_SUITS[seat]})` (player-models.js — suit GLB + drill + visible pilot, FP pose sliders apply); tick drives walk/idle from lerped speed (>0.5 → walk) + `updateAnim(dt)`. Remaining: rejected-prediction rollback (deferred), CHARGE fuse/LANTERN light VFX replication.
- **persist.js** — Phase 1.4 persistence: versioned IndexedDB snapshot store (`deepsmoke_saves`, keyPath `slot`, localStorage `ds_snap_*` fallback). `SAVE_VERSION=1`, slots `solo`/`coop`; `saveSnapshot/loadSnapshot(version-gated migrate)/deleteSnapshot/latestSnapshot`; pack helpers `packEdits/packChests/packSharedEdits(-1→0)/packSharedChests(sparse→dense)`. World save = seed + edit diff (chunks regen deterministically) + chests + player/run state. world.js supports replay via `applySavedEdit` (direct set or pre-gen `'set'` overlay edit) and exposes `seed`; upgrades.js profile carries reserved `grubLoyalty`/`blueprints`. main.js wiring (journal wrap of world.set, buildSnapshot, periodic/quit/pagehide triggers, menu CONTINUE) — see checkpoints/latest.md, NOT YET WIRED.
- **main.js** — run orchestrator wires the steam-hauler gameplay loop: per-run `hauler` state (commissioned flag, segment count, cargo slots, routeLen, transit ETA), panel open via dock interaction, commissioning via crafted `steam_hauler`, cart segment upgrades from bag `cargo_cart`, BFS route scan over connected player-laid `TRACK` blocks from dock, dispatch gating on minimum route length, route-scaled transit timing, and cargo unloading to camp storage (`campChest` first, else hauler yard chest). Hauler yard chest is now created on commission (not at run start), and NPC hauler visuals are toggled via `setHaulerState(..., built)`. Creator-only tuning now includes: camp props (`camp_prop_vacuum`, `camp_prop_forge`), player model poses (`player_model_mech/pilot/drill/drill_tp`), and NPC material/channel tuning (`npc_tub_texture`, `npc_bub_texture`), all as Star editor `tunable()` groups with live runtime apply. Main menu now includes a persistent `MINER NAME` input (profile-backed; pushed into co-op presence), DIG TOGETHER roster shows those names, and score submit now passes `{ playerName }` to leaderboard. Render loop now does a two-pass draw: world layer first, then owner first-person layer after `clearDepth()` so viewmodels always stay top-priority. Hard-landing callbacks now run through main for impact boom/camera shake (no HUD flash), nearby cracked-block cave-in triggering via shared `queueCaveIn()/triggerNearbyCaveIns()` helpers, and ground cratering via `carveBlastRadius()` — the extracted blast-charge sphere-carve helper (skips ore/relic/cache/chest/unbreakable, no drops) shared by charge detonations and landing craters. Also owns atmospheric simulation: drifting voxel cloud clusters, biome-aware weather fronts (clear/rain/snow/storm) with particle rendering + wind, and a continuous day/night lighting+fog cycle that drives sky color and scene lights in real time. Co-op chest wiring (1.2): `coop.bindChests` after client creation (~line 392, maps k→containers entry + camp-chest persist on remote change), `openChestPanel` takes the coop lock pre-open (busy → GRUB comms line; onChange → `coop.chestChanged`; onClose → `coop.chestClosed`), cave-in settle loop reports rubble via `coop.reportFill`.

State flow: main owns `score`, hazards, run state; player/grub own their fuel/cans/locked; world owns voxels. Cross-refs only through the cb objects above.
